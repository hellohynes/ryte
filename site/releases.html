v0.1.0

A fresh start for Ryte

October 30, 2026

The first release from the restarted project. Versions follow semantic versioning from here.

Installing

  • Every release is signed, notarized by Apple, and checked before it is published, including that the app’s helper processes can run.

What you get

  • Local search across your Markdown notes. Keyword search works without any API key; add a ChatGPT or Claude key for cited summaries.
  • A Preferences window, light and dark themes, quick open, and tabs for open notes.
  • One design system for dialogs, menus, tooltips, and toasts, with consistent Escape and focus behavior.

Earlier

Earlier builds

Ryte began as a project numbered by phase, from 0.1 to 0.5.1. Versioning restarted at 0.1.0 in a fresh repository, and those builds are no longer available to download. Everything they added is in the current release.

  • A read-only Markdown viewer with a sidebar, and a local index of your notes folder.
  • Local search with privacy controls, and a Preferences window.
  • Search with cited sources, and a new design system.
