v0.5.1

Fixes the damaged-app warning

October 28, 2026

A fix for the “Ryte is damaged” message some Apple Silicon Macs showed when opening 0.5.0, plus a new design foundation under the hood.

Fixes

  • The app is now ad-hoc signed, and its signature is verified before a release is published. This fixes the damaged-app warning.
  • Every release is checked by launching the packaged app before it is published.

Under the hood

  • Dialogs, menus, tooltips, and toasts share one design system, with consistent Escape and focus behavior in light and dark.
  • A custom icon set replaces the previous icons.

Installing

This build is still not notarized by Apple, so macOS may block the first launch. Installation help

v0.5.0

Search you can check, and a Preferences window

October 26, 2026

The first downloadable build: an unsigned DMG for Apple Silicon Macs. Search was rebuilt around showing where an answer came from, and settings moved into a proper Preferences window.

Search

  • Redesigned search with cited sources, so every summary points back to your notes.
  • Saved summaries and progress timelines for longer searches.
  • More reliable indexing. Local keyword search works without any API key.

Preferences

  • A Preferences window replaces Settings, and changes save as you make them.
  • Light and dark themes, and bundled fonts for reading your notes.

Getting around

  • Quick open to jump to any file by name.
  • Tabs for open notes, with keyboard navigation.
  • A home sidebar with built-in smart groups.

Installing

This build is not signed or notarized by Apple, so macOS may block the first launch. Installation help
