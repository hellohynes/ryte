Roadmap

Where Ryte is today and what is being built next. Nothing here has a date, and the order can change.

  1. Shipped

    Ryte 0.5

    A Markdown viewer with local search. Open the folder you already have, search every note on your Mac, and read them with a section outline. Add a ChatGPT or Claude key for cited summaries.

    What’s new in 0.5.1

  2. In development

    Workstreams

    A record of what your agents did. A workstream is a plain Markdown document in your notes folder: what each agent did, what is still open, and where to pick up.

    Ryte shows each one as a board and a timeline, next to your git and GitHub activity and pull request alerts.

  3. Planned

    Connect your agents

    Ryte finds the agent tools on your Mac and connects each one so it can write to a workstream. It also suggests workstreams from work already in your folders.

  4. Planned

    Comments for agents

    Leave a comment on a workstream. Your agent reads it back and marks it resolved once it has dealt with it.

  5. Planned

    Today

    A view of what needs you now across all your workstreams, and find-in-page (⌘F) inside a note.
