v0.3.0

Opens more of your work

November 11, 2026

Ryte now opens more of your work, not just notes. File viewing: pictures with a lightbox and in the file tree, video, code and JSON in a read-only view, and a Preview | Code switch. Browser tools: HTML pages in a locked box, approved local addresses such as a dev server in a locked tab, and links that open only on a real click. Plus a new note header and a tidier tab strip.

What you get

File viewing

  • Pictures in a note open larger in a lightbox when you click them.
  • Pictures show in the file tree and quick open, and open as their own tab.
  • Code and JSON files open in a read-only code view.
  • Videos play in their own tab and inside notes, with the standard controls and seeking.
  • A note has a header with the outline button and the note’s path on the left and a Preview | Code switch on the right. Text fades out as it scrolls under the header.

Browser tools

  • HTML pages open in a locked box that blocks the network, other files, and new windows, tells you what it blocked, and has an “Open in browser (not locked)” button. Links open only on a real click.
  • A link to a local address, such as a dev server, opens in a locked tab after you approve that address once or always. Allowed addresses are listed in Preferences, where you can remove them.

Good to know

  • Local pages never reach the internet or your notes.
  • You approve each local address once or always, and Ryte accepts that approval only right after a real click or key press.

v0.2.0

Search that is ready sooner

November 6, 2026

Ryte indexes your notes by keyword first, so search works as soon as the local pass finishes, and adds smart search in the background if you turn it on.

What you get

  • Keyword search is ready first. If you turn on smart search, it is added in the background, and Preferences, the status bar, and the search box say what smart search is doing. A missing key or being offline only pauses that step.
  • Each notes folder has its own index, and switching folders no longer freezes the app.
  • A note with invalid front matter or an unreadable file no longer stops the whole index pass, and the file list refreshes when you change folders.
  • Single line breaks in a note now show as line breaks, and the status bar text is easier to read in both themes.

Good to know

  • The first launch after updating can rebuild your search index once, and Ryte shows a notice when it does. With smart search on, notes are embedded again in the background.

v0.1.0

A fresh start for Ryte

October 30, 2026

The first release from the restarted project. Versions follow semantic versioning from here.

Installing

  • Every release is signed, notarized by Apple, and checked before it is published, including that the app’s helper processes can run.

What you get

  • Local search across your Markdown notes. Keyword search works without any API key; add a ChatGPT or Claude key for cited summaries.
  • A Preferences window, light and dark themes, quick open, and tabs for open notes.
  • One design system for dialogs, menus, tooltips, and toasts, with consistent Escape and focus behavior.

Earlier

Earlier builds

Ryte began as a project numbered by phase, from 0.1 to 0.5.1. Versioning restarted at 0.1.0 in a fresh repository, and those builds are no longer available to download. Everything they added is in the current release.

  • A read-only Markdown viewer with a sidebar, and a local index of your notes folder.
  • Local search with privacy controls, and a Preferences window.
  • Search with cited sources, and a new design system.
